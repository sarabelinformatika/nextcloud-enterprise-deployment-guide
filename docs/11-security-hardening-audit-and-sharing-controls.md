# 11 — Security Hardening, Audit, and Sharing Controls

Review the administration security warnings after installation and after material changes. Apply secure headers at the correct layer, protect cookies, restrict frame embedding, disable unnecessary services, and maintain file permissions.

Enable brute-force protection and appropriate rate controls. Centralize relevant application, proxy, authentication, operating-system, database, and security logs with protected retention and time synchronization.

Define alerts for repeated failures, privileged changes, new public shares, unusual downloads, blocked IPs, integrity warnings, disabled security controls, and app changes.

Server-side encryption has specific goals and limitations; it does not replace transport encryption, access control, host protection, or backup encryption. Preserve encryption keys and understand the recovery implications before enabling it.
