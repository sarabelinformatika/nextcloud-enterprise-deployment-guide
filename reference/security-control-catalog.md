# Security Control Catalog

| Domain | Minimum evidence |
|---|---|
| Identity | Named admins, MFA policy, lifecycle test, break-glass record |
| Network | Trust-boundary diagram, firewall export, trusted-proxy validation |
| Platform | Patch record, supported-version evidence, secure permissions |
| Application | Approved-app register, security-warning review, sharing policy |
| Data | Classification, storage ownership, encryption decision |
| Recovery | Backup logs, immutable/off-site evidence, restore-test record |
| Monitoring | Alert inventory, routing test, retention policy |
| Governance | Change approvals, exceptions, incident and acceptance records |
